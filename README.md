# Desktop Automation Suite

A safe automation starter suite for Windows desktop workflows. The goal is to automate repetitive actions while keeping the user in control.

## Features

- Open a prepared work session
- Generate a daily desktop note
- Preview automation actions before running them
- PowerShell and C# examples
- AutoHotkey hotkey sample

## Stack

`C#` · `PowerShell` · `AutoHotkey` · `Windows Automation`

## Safety principle

Every script in this repository is designed to be readable, reversible, and limited to local user productivity tasks.
